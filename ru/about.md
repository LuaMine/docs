# О проекте

LuaMine — это плагин для [Bukkit/Spigot](https://www.spigotmc.org/), который интегрирует скрипты на [Lua](https://www.lua.org/) в Minecraft-серверы с помощью JVM-библиотеки [luaj](https://github.com/luaj/luaj). Администраторы сервера могут писать Lua-скрипты для обработки событий, управления игроками, планирования задач и многого другого без компиляции Java-кода.

## Возможности

- **Скрипты на Lua** — Пишите `.lua` файлы в отдельной папке `scripts/`
- **Обработчики событий** — Реагируйте на вход игрока, чат, ломание блоков, взаимодействие и боевые события
- **Разнообразное API** — Отправляйте сообщения, управляйте игроками, планируйте задержанные задачи, воспроизводите звуки и отображайте заголовки
- **Горячая перезагрузка** — Перезагружайте скрипты в рантайме через `/minelua reload`
- **Без перезапусков** — Скрипты загружаются при старте сервера; изменения вступают в силу после перезагрузки плагина
