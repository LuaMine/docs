# registerCommand(name, function, description, usage)
Регистрирует Bukkit-команду (уже объявленную в `plugin.yml` вашего аддона), которая при
выполнении вызывает Lua-функцию.

| Параметр      | Тип        | Описание                                                       |
|---------------|------------|---------------------------------------------------------------------|
| `name`        | `String`   | Имя команды, совпадающее с командой, объявленной в вашем `plugin.yml` |
| `function`    | `LuaValue` | Имя Lua-функции для вызова, как строка `LuaValue.valueOf("functionName")` |
| `description` | `String`   | Описание команды                                                       |
| `usage`       | `String`   | Строка использования                                                    |

```java
api.registerCommand("mycmd", LuaValue.valueOf("onMyCommand"), "Моя команда", "/mycmd <args>");
```

Команда должна уже существовать в `plugin.yml` вашего аддона:

```yaml
commands:
  mycmd:
    description: Моя команда
    usage: /mycmd <args>
```

Lua-функция ищется **по имени** в текущем `Globals` скриптов при каждом вызове команды
(а не захватывается один раз в момент регистрации), так что скрипты могут свободно
переопределять её между `/minelua reload`, и команда подхватит актуальную версию:

```lua
function onMyCommand(sender, ...)
    -- sender — это CommandSender (консоль или игрок)
    -- ... — аргументы команды в виде строк
    mc.log("Команда выполнена!")
end
```

> **Примечание:** это другой механизм, чем когда скрипты сами вызывают
> [`mc.registerCommand`/`mc.command(...)`](../Minecraft/CommandFunctions/registerCommand.md) —
> этот предназначен для *аддонов* (Java-плагинов), чтобы зарегистрировать команду,
> обработчик которой живёт в скрипте, используя команду, которую ваш аддон уже
> статически объявил в `plugin.yml`.
