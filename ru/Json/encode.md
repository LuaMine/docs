# json.encode(value)
Преобразует Lua-таблицу (или значение) в строку JSON.

| Параметр | Тип | Описание                  |
|----------|-----|------------------------------|
| `value`  | any | Таблица/значение для кодирования |

Lua-таблицы с последовательными целочисленными ключами начиная с 1 кодируются как
JSON-массивы; всё остальное — как JSON-объект. Функции и другие несериализуемые
значения кодируются как `null`.

```lua
local json = require("json")

local text = json.encode({name = "Steve", items = {"sword", "shield"}})
mc.log(text) -- {"name":"Steve","items":["sword","shield"]}
```
