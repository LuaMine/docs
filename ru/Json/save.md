# json.save(name, value)
Сохраняет Lua-таблицу (или значение) как JSON в файл под `plugins/LuaMine/config/`.

| Параметр | Тип    | Описание                                              |
|----------|--------|------------------------------------------------------------|
| `name`   | string | Имя файла (без расширения) — см. ограничение ниже            |
| `value`  | any    | Таблица/значение для сохранения                              |

**Возвращает:** `true` при успехе, `false` если запись не удалась.

Файл записывается в `plugins/LuaMine/config/<name>.json`. `name` может содержать
только буквы, цифры, `_` и `-` — разделители пути и `..` запрещены, при попытке их
использовать выбрасывается ошибка, а не тихая обрезка. Это защита от записи файлов за
пределами папки `config/`.

```lua
local json = require("json")

json.save("player_stats", {kills = 10, deaths = 2})
```
