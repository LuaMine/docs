# mc.title(player, title, subtitle)
Отображает заголовок и субтитр игроку.

| Параметр    | Тип      | Описание                                 |
|-------------|----------|------------------------------------------|
| `player`    | userdata | Объект игрока                            |
| `title`     | string   | Основной заголовок (поддерживает `&` коды) |
| `subtitle`  | string   | Субтитр (поддерживает `&` коды)          |

```lua
mc.title(player, "&aДобро пожаловать!", "&eПриятного пребывания")
```
