# mc.sound(player, soundName)
Проигрывает звуковой эффект игроку.

| Параметр    | Тип      | Описание                                                        |
|-------------|----------|-----------------------------------------------------------------|
| `player`    | userdata | Объект игрока                                                   |
| `soundName` | string   | Название звука (регистр не важен, например `"entity_explode"`) |

```lua
mc.sound(player, "ENTITY_EXPLODE")
```
