# mc.color(text)
Преобразует коды `&` в цветовые коды Minecraft.

| Параметр  | Тип      | Описание                              |
|-----------|----------|---------------------------------------|
| `text`    | string   | Текст с кодами `&`                    |

**Возвращает:** строку

```lua
local colored = mc.color("&cКрасный текст &aЗелёный текст")
```
