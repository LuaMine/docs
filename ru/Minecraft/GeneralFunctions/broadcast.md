# mc.broadcast(message)
Отправляет сообщение всем онлайн-игрокам.

| Параметр  | Тип      | Описание                                   |
|-----------|----------|--------------------------------------------|
| `message` | string   | Сообщение (поддерживает цветовые коды `&`)  |

```lua
mc.broadcast("&aДобро пожаловать на сервер!")
```
