# mc.getBlock(x, y, z, world)
Получает тип блока по указанным координатам.

| Параметр | Тип    | Описание                                                       |
|----------|--------|---------------------------------------------------------------------|
| `x`      | number | Координата X                                                          |
| `y`      | number | Координата Y                                                          |
| `z`      | number | Координата Z                                                          |
| `world`  | string | *(необязательно)* Имя мира. По умолчанию — первый/основной мир сервера   |

**Возвращает:** имя материала (строка), или `nil`, если указанного мира не существует.

```lua
local block = mc.getBlock(0, 100, 0)
mc.log("Блок: " .. block)
```
