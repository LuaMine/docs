# mc.spawnEntity(type, x, y, z, world)
Создаёт сущность в указанных координатах.

| Параметр | Тип    | Описание                                                       |
|----------|--------|---------------------------------------------------------------------|
| `type`   | string | Имя типа сущности (например `"ZOMBIE"`, `"COW"`, `"ARROW"`)             |
| `x`      | number | Координата X                                                          |
| `y`      | number | Координата Y                                                          |
| `z`      | number | Координата Z                                                          |
| `world`  | string | *(необязательно)* Имя мира. По умолчанию — первый/основной мир сервера   |

Выбрасывает ошибку, если `type` не является распознанным типом сущности.

```lua
mc.spawnEntity("ZOMBIE", 0, 101, 0)
```
