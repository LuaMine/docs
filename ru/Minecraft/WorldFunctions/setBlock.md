# mc.setBlock(x, y, z, type, world)
Устанавливает тип блока по указанным координатам.

| Параметр | Тип    | Описание                                                       |
|----------|--------|---------------------------------------------------------------------|
| `x`      | number | Координата X                                                          |
| `y`      | number | Координата Y                                                          |
| `z`      | number | Координата Z                                                          |
| `type`   | string | Имя материала блока (например `"STONE"`, `"DIAMOND_BLOCK"`)             |
| `world`  | string | *(необязательно)* Имя мира. По умолчанию — первый/основной мир сервера   |

Выбрасывает ошибку, если `type` не является распознанным материалом блока.

```lua
mc.setBlock(0, 100, 0, "DIAMOND_BLOCK")
mc.setBlock(0, 64, 0, "GLASS", "world_nether")
```
