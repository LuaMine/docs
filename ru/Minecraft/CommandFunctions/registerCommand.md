# mc.registerCommand(name, function, description, usage)
Регистрирует пользовательскую команду, которая при вызове выполняет Lua-функцию.

| Параметр      | Тип      | Описание                                                    |
|---------------|----------|----------------------------------------------------------------|
| `name`        | string   | Имя команды, без ведущего `/`                                   |
| `function`    | function | Вызывается как `function(sender, args)` при выполнении команды  |
| `description` | string   | *(необязательно)* Отображается в `/help`                        |
| `usage`       | string   | *(необязательно)* Строка использования, по умолчанию `/name`    |

Колбэк получает `sender` (`CommandSender`, вызвавший команду — игрок или консоль) и
`args` — Lua-таблицу с индексацией с 1, содержащую аргументы, введённые после имени
команды.

Повторный вызов `registerCommand` с уже зарегистрированным именем заменяет функцию,
которая выполняется при вызове этой команды — именно это происходит автоматически при
перезагрузке скриптов через `/minelua reload`, так что переопределение команды в
скрипте и последующий reload всегда подхватывают актуальную версию.

```lua
mc.registerCommand("greet", function(sender, args)
    local name = args[1] or "friend"
    mc.sendMessage(sender, "&aПривет, " .. name .. "!")
end, "Приветствует кого-либо", "/greet <имя>")
```

> **Примечание:** `sender` — это "сырой" Java-объект `CommandSender` (не та же
> обёрнутая таблица, что получают колбэки событий вроде `onPlayerJoin`), поэтому у него
> нет методов `player:xxx()`, описанных в разделе
> [Функции игрока](../PlayerFunctions/index.yaml). Используйте свободные функции
> `Minecraft.xxx(player, ...)` (например, `mc.sendMessage(sender, ...)`,
> `mc.kick(sender, ...)`), которые работают и с тем, и с другим.

## Автодополнение: билдер `mc.command(name)`

`registerCommand` не поддерживает автодополнение (добавлять пятый позиционный параметр
показалось неправильным направлением). Если оно нужно — используйте fluent-билдер: он
в итоге регистрирует ту же самую команду, просто через именованные методы:

```lua
mc.command("heal")
    :execute(function(sender, args)
        mc.sendMessage(sender, "&aВы исцелены!")
    end)
    :description("Лечит вас")
    :usage("/heal [amount]")
    :tabComplete(function(sender, args)
        return {"10", "20", "full"}
    end)
    :register()
```

| Метод                     | Обязателен | Описание                                                            |
|----------------------------|------------|------------------------------------------------------------------------|
| `:execute(function)`       | Да         | Та же сигнатура, что у функции в `registerCommand`                      |
| `:description(string)`     | Нет        | Отображается в `/help`                                                   |
| `:usage(string)`           | Нет        | Строка использования, по умолчанию `/name`                               |
| `:tabComplete(function)`   | Нет        | Вызывается как `function(sender, args)`; верните таблицу строк-подсказок |
| `:register()`              | -          | Завершает регистрацию — должен вызываться последним                     |

Ничего не происходит, пока не вызван `:register()`. Повторный вызов позже (например, при
`/minelua reload`) обновляет ту же самую команду на месте, как и `registerCommand`.
