# player:setHealth(value)
Устанавливает текущее здоровье игрока.

| Параметр | Тип    | Описание                                                  |
|----------|--------|--------------------------------------------------------------|
| `value`  | number | Новое здоровье (не может превышать максимальное здоровье игрока) |

```lua
player:setHealth(10) -- 5 сердец
```
