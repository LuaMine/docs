# player:giveItem(item, amount)
Выдаёт игроку предмет.

| Параметр | Тип    | Описание                                     |
|----------|--------|--------------------------------------------------|
| `item`   | string | Имя материала предмета (например `"DIAMOND"`)      |
| `amount` | number | *(необязательно)* Количество. По умолчанию `1`.      |

Выбрасывает ошибку, если `item` не является распознанным материалом.

```lua
player:giveItem("DIAMOND", 5)
```
