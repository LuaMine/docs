# player:addEffect(name, duration, amplifier)
Накладывает на игрока эффект зелья.

| Параметр    | Тип    | Описание                                                                |
|-------------|--------|--------------------------------------------------------------------------|
| `name`      | string | Имя эффекта (`PotionEffectType` из Bukkit, например `"SPEED"`, `"REGENERATION"`) |
| `duration`  | number | Длительность в тиках сервера (20 тиков = 1 секунда)                        |
| `amplifier` | number | *(необязательно)* Уровень эффекта, 0 = уровень I. По умолчанию `0`.         |

Неизвестные имена эффектов молча игнорируются.

```lua
player:addEffect("SPEED", 200, 1) -- Скорость II на 10 секунд
```
