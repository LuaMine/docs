# player:hasItem(item, amount)
Проверяет, есть ли у игрока в инвентаре хотя бы указанное количество предмета.

| Параметр | Тип    | Описание                                              |
|----------|--------|------------------------------------------------------------|
| `item`   | string | Имя материала предмета (например `"DIAMOND"`)                |
| `amount` | number | *(необязательно)* Минимальное необходимое количество. По умолчанию `1`. |

**Возвращает:** булево значение.

Выбрасывает ошибку, если `item` не является распознанным материалом.

```lua
if player:hasItem("DIAMOND", 10) then
    mc.sendMessage(player, "&aУ вас есть 10+ алмазов!")
end
```
