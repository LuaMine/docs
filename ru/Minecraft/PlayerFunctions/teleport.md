# player:teleport(x, y, z)
Телепортирует игрока в указанную позицию в его текущем мире.

| Параметр | Тип    | Описание                |
|----------|--------|---------------------------|
| `x`      | number | Целевая координата X        |
| `y`      | number | Целевая координата Y        |
| `z`      | number | Целевая координата Z        |

```lua
player:teleport(0, 100, 0)
```
