# mc.kick(player, reason)
Выгоняет игрока с сервера.

| Параметр  | Тип      | Описание                            |
|-----------|----------|-------------------------------------|
| `player`  | userdata | Объект игрока                       |
| `reason`  | string   | Причина кика (поддерживает коды `&`) |

```lua
mc.kick(player, "&cВы были кикнуты!")
```

> **Примечание:** также доступно как `player:kick(reason)`.
