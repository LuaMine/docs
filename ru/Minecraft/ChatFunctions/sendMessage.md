# mc.sendMessage(player, message)
Отправляет сообщение конкретному игроку.

| Параметр  | Тип      | Описание                                   |
|-----------|----------|--------------------------------------------|
| `player`  | userdata | Объект игрока                              |
| `message` | string   | Сообщение (поддерживает цветовые коды `&`)  |

```lua
mc.sendMessage(player, "&aПривет!")
```
