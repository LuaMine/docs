# mc.wait(ticks, callback)
Выполняет callback-функцию с задержкой в тиках сервера (20 тиков = 1 секунда).

| Параметр   | Тип       | Описание                             |
|------------|-----------|--------------------------------------|
| `ticks`    | number    | Задержка в тиках сервера             |
| `callback` | function  | Функция, вызываемая после задержки   |

```lua
mc.wait(20, function()
    mc.broadcast("&eПрошла 1 секунда!")
end)
```
