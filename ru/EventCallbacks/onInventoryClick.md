# onInventoryClick(player, slot, itemType)
Вызывается, когда игрок кликает по слоту в любом открытом инвентаре.

| Параметр   | Тип      | Описание                                                     |
|------------|----------|------------------------------------------------------------------|
| `player`   | userdata | Кликающий игрок                                                    |
| `slot`     | number   | Индекс слота, по которому кликнули                                   |
| `itemType` | string   | Имя материала предмета в слоте, или `nil`, если слот пуст            |

Верните строку `"cancel"`, чтобы отменить клик (например, чтобы заблокировать предметы
на месте внутри кастомного GUI/меню магазина).

```lua
function onInventoryClick(player, slot, itemType)
    if itemType == "BEDROCK" then
        return "cancel"
    end
end
```
