# onPlayerInteract(player)
Вызывается, когда игрок щелкает правой кнопкой мыши в воздухе (только для основной руки).

| Параметр  | Тип      | Описание               |
|-----------|----------|------------------------|
| `player`  | userdata | Игрок, взаимодействующий|

```lua
function onPlayerInteract(player)
    mc.sendMessage(player, "&aВзаимодействие обнаружено!")
end
```
