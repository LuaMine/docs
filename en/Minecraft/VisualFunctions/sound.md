# mc.sound(player, soundName)
Plays a sound effect for a player.

| Param       | Type     | Description                                        |
|-------------|----------|----------------------------------------------------|
| `player`    | userdata | Player object                                      |
| `soundName` | string   | Sound name (case-insensitive, e.g. `"entity_explode"`) |

```lua
mc.sound(player, "ENTITY_EXPLODE")
```
